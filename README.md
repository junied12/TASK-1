Simple Interest Calculator
Introduction

This project is a simple interest calculator.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Inputs
Principal Amount
Rate of Interest
Time Period
Example

Principal = 1000 Rate = 5% Time = 2 years

Simple Interest = 100

Technologies Used
HTML
CSS
JavaScript
Description

This calculator helps users calculate simple interest easily by entering the principal amount, rate of interest, and time period.
